附录 A · 环境配置 ​

先备好 Python 3.12，再从下面的实验包开始。第 1 章可在 CPU 上运行，模型单独下载。其他章节使用的模型和设备列在本页后半部分。

准备第一个实验 ​

  1. 下载配套实验包（ZIP）并解压。进入包含 pyproject.toml、experiments/ 和 pi_infer/ 的 pi-infer-labs 目录。
  2. 在这个目录打开终端，运行 python -m venv .venv。Windows PowerShell 用 .\.venv\Scripts\Activate.ps1 激活，Linux 或 macOS 用 source .venv/bin/activate。
  3. 安装下面的 CPU 依赖，然后按「模型」一节下载 Qwen3-0.6B 到 models/qwen3-0.6b。各章命令均从同一个实验包根目录执行。

本机基线（CPU 路径，第 1–12、16 章全部实验） ​

bash
# Windows / Linux CPU，Python 3.12
python -m pip install torch==2.15.0 --index-url https://download.pytorch.org/whl/cpu
python -m pip install transformers==5.22.1 pytest==9.2.0
python -m pip install -e .
python -m pytest pi_infer/tests/test_kv.py -q  # 无需模型权重，先验证安装

独立应用环境（按章选做，本机未测） ​

  • 第 13 章 VLM 执行侧：Linux/CUDA，transformers≥4.57（或 5.x）+ bf16 4B 权重（≈8.9GB），≥12GB 显存；复现命令在 experiments/exp_ch13_vlm/README.md。
  • 第 14 章视频：官方 Wan2.2 仓库环境 + ≥24GB VRAM GPU，权重约 34GB；experiments/exp_ch14_video/README.md。
  • 第 15 章 vLLM：Linux/CUDA + vLLM（启动前架构核查）；experiments/exp_ch15_deploy/README.md。
